# Eruru.HttpZipStream

AOT-compatible. A stream implemented via HTTP Range request headers, enabling online preview of the file list and downloading of required files without fully downloading the ZIP file, saving network bandwidth and time.

AOT兼容，通过HTTP Range请求头实现的Stream，无需完整下载ZIP文件即可在线预览文件列表并下载所需文件，节省流量和时间
